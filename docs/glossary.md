# Glossary

- **Status:** Approved

Code, API and specs use the English term; the UI shows the user's language.

| English (code) | Finnish (UI) | Meaning |
|---|---|---|
| Gig | Keikka | A sold performance |
| Sold | Myyty | Gig status; shown as "played" once the date has passed |
| Played | Soitettu | Display only: a Sold gig with a past date |
| Cancelled | Peruttu | Gig status |
| Uncancel | Palauta | Cancelled → Sold, with reason |
| Move | Siirrä | Change a gig's dates |
| Soft delete | Poisto (palautettava) | Hidden but restorable |
| History | Muutoshistoria | Full log of changes on a gig |
| Lineup | Kokoonpano | Band configuration of a gig |
| Lineup template | Kokoonpanopohja | Standard lineup with roles and default fees (seed) |
| Venue | Paikka | Where the gig is |
| Technical setup | Tekniikka | House tech or own PA set A/B/C (one choice) |
| Logistics | Logistiikka | Own van, rental van, taxi, other |
| House technician | Talon teknikko | Venue provides a technician (yes/no) |
| Price | Hinta (alv 0 %) | Agreed price excl. VAT |
| Additional sales | Lisämyynti | Extra sold on top (amount + description) |
| Total price | Kokonaishinta | Price + additional sales |
| Cost line | Kulurivi | A fee or expense on a gig |
| Budgeted amount | Budjetti | Planned cost |
| Actual amount | Toteuma | Paid cost |
| Mark paid | Merkitse maksetuksi | Records actual amount, time and partner |
| Load-in & soundcheck | Roudaus ja soundcheck | Included in a fee; switching off deducts a set amount |
| Margin / Margin % | Kate / Kate-% | Total price − costs / ÷ total price |
| Seller / Producer | Myyjä / Tuottaja | Partners who sold / deliver the gig |
| Office / Sales / Production | Toimisto / Myynti / Tuotanto | Internal fee lines |
| Not fully staffed | Miehitys kesken | A musician role has no person |
| Person | Henkilö | Someone who can be put on a gig |
| Partner | Osakas | A system user |
| Attachment | Liite | File on a gig, e.g. the contract |
| Contract | Sopimus | Holds customer, invoicing, payment and cancellation terms |
| Task | Tehtävä | To-do item, Open or Done |
| Hour entry | Tuntikirjaus | Date, comment, hours |
| Year / selected year | Vuosi / valittu vuosi | Primary reporting dimension |
| Sold gigs sum | Myytyjen keikkojen summa | Σ total price of the year's gigs |
| Hours sum | Tuntisumma | Σ hours in the year |
| Budget category | Budjettikategoria | Fixed cost/income category (seed) |
| Variance | Poikkeama | Budget − actual |
| Year result | Vuoden tulos | Sold gigs sum − gig costs + fixed income − fixed expenses |
| Setting | Asetus | Seeded business value |
